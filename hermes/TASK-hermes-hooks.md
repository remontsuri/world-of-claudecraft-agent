# Перенесено

Канонический файл задания для hermes — **`hermes/PROMPT-hermes-task.md`**.

Этот файл заменён указателем 2026-09-20, чтобы не держать две расходящиеся
версии одного задания. Причины переноса:

- новый файл автономный: текст системной секции (3101 знак) и каркас плагина
  встроены в него, внешние `PROMPT.md` / `PROMPT.section-A.txt` читать не
  обязательно;
- путь к репозиторию не зашит — определяется через `git rev-parse
  --show-toplevel` и обозначается `<REPO>`;
- добавлен П0 «Разведка» (версия hermes, абсолютный путь Python, наличие bash,
  версия Vitest, работает ли `tool_repetition`) — без него на Windows задание
  упирается в неизвестные пути;
- добавлены Windows-специфика shell-хуков (`shlex.split` съедает обратный слэш,
  `shell=False`, UTF-8 в `.cmd`, `.gitattributes`), образец `.cmd`-обёртки и
  готовый блок `hooks:` с реальными matcher'ами.

Файлы `hermes/PROMPT.md` и `hermes/PROMPT.section-A.txt` остаются в силе как
справочник (секции A/B, источники, сравнение вариантов).
