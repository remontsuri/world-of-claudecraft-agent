Ты — аудитор обучающего контура. Стек ВЫКЛЮЧЕН (агент не запущен), мост

## Заявленная цепочка

```
мир -> снапшот -> WorldState -> policy.decide -> скилл -> verifier ->
reward -> ExperienceStore (Q, TD) -> replay -> SelfReflection (hints) ->
StrategyMemory -> следующее решение
```

**Рефлексия:** все 5 записей одного типа `ACTION_SATURATION` («скилл занял

**Важный контекст:** только что найден баг, из-за которого `quests_done`
всегда был 0, хотя реально сдано 7 квестов. Значит ВСЯ история обучения
получала ложный отрицательный сигнал на сдачу квестов.

## Практики из литературы (для сверки, не для копирования)

- **Reflexion** (arXiv 2303.11366): Actor → Evaluator → Self-Reflection;
  вербальные уроки в эпизодической памяти дают +8% против хранения одних
  траекторий; буфер ограничен 1-3 свежими рефлексиями.
- **Potential-based reward shaping** (Ng 1999): `F(s,s') = γΦ(s') − Φ(s)`
  сохраняет оптимальную политику; эквивалентно инициализации Q значениями Φ.
- **Curriculum + PBRS** для разреженных награда в текстовых играх (Stanford
  CS224R 2025): без них агент не находит сигнал.
