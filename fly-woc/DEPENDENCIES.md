# Зависимости fly-линии

Версии — те, на которых всё проверено. Для каждой зависимости сказано, что именно
она держит, чтобы при обновлении было понятно, что перепроверять.

## Runtime (активная линия)

| Что | Версия (проверено) | Что держит | Где нужно |
|---|---|---|---|
| Python | 3.13 | весь код линии | везде |
| PyTorch | 2.14.0+cpu в песочнице; на машине нужен **CUDA-сборка** | схема (`edge`/`sparse`), читаут, PPO | обучение, GPU-прогон |
| NumPy | 2.x (идёт с torch) | массивы схемы, фичи, метрики | везде |
| SciPy | любая свежая | `scipy`-бэкенд схемы (CPU-эталон) и COO | CPU-прогон, тесты |
| Node.js | 20.x | headless-симуляция игры (`python/wow_env.py` поднимает node) | живой прогон, e2e |
| pnpm | 10.34.5 | запуск офлайн-игры | живой прогон |
| Pillow (опц.) | — | только для наблюдения за игрой глазами | по желанию |

Проверка окружения: `python3 fly-woc/tools/gpu_check.py --device cpu` (или `cuda`).
Сборка torch под GPU на Windows ставится с индекс-URL CUDA; CPU-сборка честно скажет
`сборка CUDA: нет`.

| `fly-woc/data/circuit.json` | 25 МБ | наша схема: 8835 узлов, 1.87M рёбер, 52 входа, 82 DN, 13 каналов | **коммитим** (это часть воспроизводимости) |

Данные MaleCNS (166 700 нейронов, ~125 млн синапсов) — **CC BY 4.0**: атрибуция
обязательна. Полные веса не качаем и не кладём в репозиторий (LFS исчерпан;
>100 МБ — только в Releases).

## Переменные окружения

| Переменная | Значение | Зачем |
|---|---|---|
| `WOC_PYTHON_PATH` | путь к чекауту игры (`python/wow_env.py`) | обучение и замеры против живой среды |
| `WOC_DEVICE` | `cuda` / `mps` / `cpu` | устройство, если не задан `--device` |
| `WOC_BRAIN_BACKEND` | `auto` / `edge` / `sparse` / `scipy` | бэкенд схемы |
| `WOC_QUEST_TABLE` | путь к таблице | таблица оракула под конкретную сборку |
| `WOC_QUEST_TABLE_ALLOW_SHORT` | `1` | только явное разрешение короткой таблицы (префикс) |
| `FLY_FEATURES` | `v1` / `v2` | версия энкодера наблюдений |

## Чего НЕ требуем и не используем

* Maven/Gradle — не относятся к этой линии.
* Brian2 и чужие LIF-пакеты — только как эталон сверки, не как зависимость:
  наша динамика переносится из своего же `src/fly_brain/engine.py`.
* Полные данные CNS и GPU-обвес (CuPy/numba) — пока не нужны: активная схема
  это 8835 нейронов, её тянет обычный torch.
