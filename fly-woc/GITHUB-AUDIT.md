## 5. Вес `.git`: 186 МБ истории против 116 МБ дерева

`.git` = **185.46 MiB** в одном пакете, 3 096 объектов. Дерево при этом 116 МБ — значит
**~70 МБ приходится на то, чего в проекте уже нет.** Вся история по расширениям
(несжатые размеры блобов):

| Тип | Вес в истории | Файлов | Комментарий |
|---|---|---|---|
| `.zip` | **218.2 МБ** | 15 | сюда попал `woc_online_agent_FULL.zip` — **94.6 МБ**, добавлен в `489c179` («initial snapshot»), удалён в `4440ff2` |
| `.json` | 163.6 МБ | 320 | коннектомы (в т.ч. удалённые копии) |
| `.jsonl` | 44.2 МБ | 1 | `autonomy_log.jsonl` — лог, тоже удалён из дерева |
| `.pt` | 14.9 МБ | 29 | чек-инты |
| `.py` | 12.7 МБ | 905 | код (много удалённого) |
| `.png` | 10.3 МБ | 14 | скриншоты проб |
| `.cjs` | 2.9 МБ | 256 | диагностические скрипты (удалены) |

Важное следствие, которое стоит помнить: **«переклонировать `backup` перед пушем» = каждый
раз качать 186 МБ**, хотя полезного там ~110 МБ. Плюс GitHub держит этот вес навсегда:
удаление файла новым коммитом вес не уменьшает.

Чистка возможна (`git filter-repo`/BFG), но она **переписывает историю и требует
force-push** — а это прямо запрещено нашими правилами («никогда не force-push», «коммиты
`Your Name` не откатывать»). Поэтому рекомендация не «почистить», а «не добавлять тяжёлое
и не размножать коннектомы».

## 10. Команды, которыми это проверено

```bash
# полный клон всех веток и разбор
git clone https://github.com/remontsuri/world-of-claudecraft-agent.git
git rev-list --count origin/backup            # 349
git merge-base origin/backup origin/master    # 88469d2  → master не впереди

# вес дерева и дубликаты
git ls-files -z | xargs -0 du -b | sort -rn | head
sha256sum fly-woc/data/circuit.json data/circuit*/circuit.json

# вес истории и самые тяжёлые блобы
git count-objects -vH                          # size-pack 185.46 MiB
git rev-list --objects --all | git cat-file --batch-check='%(objecttype) %(objectsize) %(rest)' \
  | awk '$1=="blob" && $2>5000000'

# скан истории на секреты (0 совпадений)
git grep -I -n -E 'ghp_[A-Za-z0-9]{20,}|github_pat_[A-Za-z0-9_]{20,}|sk-[A-Za-z0-9]{32,}|AKIA[0-9A-Z]{16}' $(git rev-list --all)
```
