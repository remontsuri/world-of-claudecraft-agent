## Обязывающие проектные ограничения (7 пунктов, приняты обоими)

1. Логистика (accept / return / turn_in / sell) — **детерминированные
   факт-исполнители, вне Q-learning**. Q остаётся бою и микро-решениям.
2. LLM либо получает реальный рычаг, либо уходит из горячего цикла.
   Текущая проводка (LLM пишет goal, `update_from_world` его перезаписывает)
   покупает латентность, не поведение.
3. **Один писатель goal.** Сейчас их два — FSM и brain.
4. Побег из боя — к **запомненному safe-anchor**, не в случайную сторону.
5. Награда за turn_in — **только по `verify_quest_turn_in == success`**.
   Навигационные leg'и награды не дают (иначе nav-тредмилл: return давал
   +0.31 при нулевом прогрессе квестов).
6. **Оффлайн-merge всех исторических логов запрещён** — проверено на
   практике: deaths +23, залипание в farm. Только post-fix редкие события.
7. Один навигатор: `nav_policy` primary, остальные — fallback.

| 5 | LLM → периодический автор хинтов (асинхронно, ~раз в 100 шагов) | llm-модуль, `policy.load_reflection_hints` | 0 блокирующих вызовов в `decide()`; ≤10 вызовов / 1000 шагов | далее |

Обоснование порядка (аргумент со-архитектора, принят): `cands.remove()`
выполняется в `_candidates()` **до** `candidate_values()` и softmax, поэтому
никакой prior не спасёт вырезанное действие — фикс #1 обязан быть первым.

## Боевой бакет после сокращения (шаг 4)

Оставить: `hp_band(4)`, `strong_mob_near`, `weak_mob_near`, `has_mob`,
`has_corpse`, `danger`, `in_combat` → ≤256 комбинаций.
Убрать из боевого бакета: `junk` (→ логистика продажи), `far`/дистанция до
гивера (→ детерминированная навигация), `quest_status` (→ фаза FSM).
Причина: эти признаки не меняют выбор боевого скилла, но раздували
пространство ключей вчетверо.

## Приёмочный тест «полностью автономный агент»

Агент считается автономным, когда ВСЕ шесть выполнены на одном прогоне:

| Критерий | Метрика | Цель |
|---|---|---|
| Проходимость квестов | `quests_done` delta за 5000 шагов | ≥ 10 |
| Надёжность сдачи | `verify_quest_turn_in == success` / попытки | ≥ 0.90 |
| Выживаемость | смертей на 1000 шагов | ≤ 2.0 (приёмка), ≤ 1.0 (цель) |
| Самосохранение | `P(heal \| hp_frac < 0.35)` | ≥ 0.70 |
| Кривая обучения | 2-я половина 10000 шагов vs 1-я | ≥ 1.25× квестов И ≤ 0.7× смертей |
| Независимость от LLM | блокирующих вызовов в `decide()` | 0 (периодических ≤ 10/1000) |

Текущее состояние против цели (последний измеренный прогон, 1288 шагов):
квестов сдано 0 (цель ≥10/5000), смертей 10/1288 ≈ 7.8 на 1000 (цель ≤2.0),
доля heal 22% (косвенно нарушает бюджет шагов), LLM в горячем цикле.
