# V0-browser baseline — протокол прогона

**Статус: ИДЁТ** (запущен 2026-08-27)

## Фиксация эксперимента

| Параметр | Значение |
|---|---|
| commit | `33b7134de` |
| режим | **browser** (реальный offline-клиент, контур говорит 13 навыками) |
| шагов | **1000** (при измеренных 0.13 шаг/сек ≈ 2 ч 8 мин) |
| правка кода во время прогона | **НЕТ** |
| старт | `respawn` → `snapshot` |
| обучение PPO во время замера | **НЕТ** (политика зафиксирована как V0) |
| `WOC_AUTONOMY` | 1 (fail-closed: провал контракта останавливает процесс) |
| `WOC_BRAIN` | off (LLM вне горячего контура) |
| `WOC_TRACE` | 0 (трассировка шага выключена, чтобы не мерить свой же I/O) |

Почему 1000, а не 5000: темп измерен на пробе — 18 шагов за 135 с = 0.13
шаг/сек. 5000 шагов = 10.4 часа и дают тот же ответ о распределении, что
1000 за 2 часа. Если метрики окажутся нестабильными — второй прогон на 1000,
а не сразу 5000.

## Фактическое стартовое состояние

Записано ПОСЛЕ respawn, без подгонки. Неидеальные части зафиксированы как есть.

```
player_class   warrior
hp             100 / 100        dead=false     in_combat=false
level          1
position       [-0.53, 32.99]
inventory      {}               <- ПУСТО: хлеб съеден в пробе, respawn его не возвращает
equipment      mainhand=worn_sword, chest=recruit_tunic, offhand=eastbrook_buckler
copper         0
kills          2                <- не ноль: наследие пробного прогона
deaths         5                <- не ноль: наследие пробного прогона
quests_done    0
quests_active  [(q_wolves, active)]
nearby         36 сущностей, 16 живых мобов
ближайшие      Forest Wolf maxHp 40-54, дистанция 25.6-43.8
```

Существенно для чтения результата:
- **сумка пуста** — значит `heal` не имеет ресурса с самого начала, и все
  его не-успехи в этом прогоне относятся к категории «ресурса нет», а не
  «heal сломан». Различить помогает `inventory_count` в трассе каждого шага.
- `kills=2 / deaths=5` — счётчики не сброшены, это наследие пробы. Все
  выводы делаются по **дельтам**, не по абсолютным значениям.
- мобы 40–54 HP на 25–44 ярдах — это НЕ та зона смерти (Warlord Drogmar
  1564 HP), с которой мы боролись раньше. Старт адекватный для level 1.

## Что записывается

Файл `python/v0_trace.json`, дамп каждые 50 записей (прерванный прогон
остаётся анализируемым).

Учёт шагов — раздельно, потому что `nav_command` делает `continue` до
`agent.step()`:
`environment_steps`, `learning_steps`, `nav_substeps`, `skill_attempts`.
1000 итераций среды ≠ 1000 обучающих переходов.

По каждому шагу: `skill`, `result`, **`failure_reason`**, `subgoal`, `goal`,
`reward`, `hp`, `max_hp`, `in_combat`, `inventory_count`, `inventory`,
`recovery`.

Сводка контура (`autonomy_stats`): success/failure/no_op + их rate,
`recoveries`, `recoveries_executed`, `loops_tripped`, `nav_commands`,
`nav_arrived`, `nav_stuck`, `abandoned`, `blacklist_skips`, `masked_out`,
`subgoals`.

## Правило чтения результата

Первый найденный дефект **не чинится** посреди прогона и не чинится сразу
после. Порядок:

```
V0 report -> root-cause ranking -> fix #1 -> regression test -> V1
          -> PPO training -> V1 evaluation -> V1 > V0 ?
```

Без сравнения на НОВЫХ эпизодах улучшение недоказуемо.
