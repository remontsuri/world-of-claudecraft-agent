# Аудит Java-агента (ветка `master`, 2026-09-16)

Проверка кода на состояние «работает / заглушка» и первый сквозной прогон.
Всё, что ниже помечено «проверено», воспроизводится командой
`bash tools/run_e2e.sh` (полигон `tools/fake_bridge.cjs`, без игры и браузера).

## Что было сломано (найдено чтением + прогонами)

| Место | Было | Последствие |
|---|---|---|
| `VoyagerAgent.executeSkill` | `{"action":"step","skill":N}` | Мост ждёт `idx` → шаг не выполнялся бы вообще |
| `VoyagerAgent.executeSkill` | `{"action":"raw_move","direction":"back"}` | Мост ждёт `kind` → побег не работал |
| Таблица навыков в `VoyagerAgent` | heal→8, equip не было, buy→5, gather→6 | `idx` не совпадал с `actions.cjs`: «heal» вызывал equip, «buy» — gather |
| `GameEnvironment.snapshot()` | возвращал кэш, запросов не делал | Агент «наблюдал» пустое состояние |
| `GameEnvironment.step()` | возвращал пустой объект | Навыки не исполнялись |
| `AgentCore.executeSkill` | `return "SUCCESS"` без обращений к игре | Цикл отчитывался об успехе, ничего не делая |
| `BridgeServer` | зашитый GUID вкладки CDP `CC6F6E01…`, `evaluate()` возвращал `{"ok":true}` не дожидаясь ответа | Мост не мог подключиться ни к какой вкладке, кроме одной конкретной сессии |
| `ArbitrationLayer.selectBest` | при активном квесте всегда выбирал `return_to_giver` | Агент бегал к NPC вместо выполнения цели |
| `GoalFSM` | фазы переключались вручную в исполнителе | Гейты фаз работали по устаревшему состоянию |
| Координаты NPC | зашитые `(2.84, 9.72)` в трёх местах | Верно для одного квеста; для остальных — бег в никуда |
| `Bootstrap` | поднимал нерабочий `BridgeServer` | Точка входа не могла работать в принципе |

## Что сделано

* `core/SkillIndex.java` — единая таблица `0…12`, совпадающая с
  `python/hierarchical_env.py` и `src/bridge/actions.cjs`; неизвестный навык — исключение,
  а не «примерно тот» индекс.
* `env/GameEnvironment.java` — настоящий HTTP-клиент моста (snapshot/step/raw_move/navigate/
  respawn/explore/health), `callQuiet` с диагностикой; кэша больше нет.
* `env/SnapshotMapper.java` — единственный разбор снимка в `WorldState` (игрок, nearby с
  `quest_target/lootable/looted`, квесты active/ready/done с `turnInNpc`, `quests_done`,
  `quest_cadence_blocked`). Отсутствующие поля не перетираются нулём.
* `fsm/GoalFSM.syncFrom(ws)` — фаза выводится из наблюдения; счётчик сдач.
* `arbitration/ArbitrationLayer.java` — приоритет: сдача → приём → бой → обыск → подход →
  разведка; провалившийся навык уходит на перерыв (3 провала → 60 решений).
* `core/SkillExecutor.java` — одно исполнение навыков для `AgentCore` и `VoyagerAgent`;
  координаты берутся из снимка и памяти, зашитых точек нет.
* `bridge/BridgeServer.java` — Java-мост с тем же контрактом; `UpstreamBackend` уже
  работает, `CdpBackend` честно объявлен непортированным.
