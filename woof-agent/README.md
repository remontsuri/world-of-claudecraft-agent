# woof-agent — автономный Java-бот World of Claudecraft

Бот сам играет в локальную копию World of Claudecraft: смотрит состояние мира через мост,
решает, что делать (квесты, бой, сбор, возврат), и отдаёт действия обратно в игру.
Без браузерной автоматизации «по пикселям»: всё идёт через один HTTP-контракт.

## Быстрый старт (без игры)

```bash
bash tools/build.sh          # javac + libs/*.jar, Maven не нужен
bash tools/run_tests.sh      # 3 набора: SkillIndex / CdpClient / JavaBridge
bash tools/run_e2e.sh        # полный прогон против фейковой игры и фейкового CDP
```

`run_e2e.sh` — это приёмка: он поднимает фейковый мост и фейковый CDP, гоняет агента
и печатает `[Agent] SUMMARY ...`. Критерий успеха — строка `УСПЕХ: квест сдан обоими
путями (Node-мост и Java-мост), нарушений контракта нет`.

## Быстрый старт (живая игра)

```bash
# 1) игра уже запущена пользователем на http://localhost:5173
# 2) мост: чистый Java (сам говорит с CDP :9222)
java -cp "build/classes:libs/*" com.woof.agent.bridge.BridgeMain
#    либо Java впереди, Node-мост за ним
java -cp "build/classes:libs/*" com.woof.agent.bridge.BridgeMain --upstream http://127.0.0.1:8791

# 3) агент
java -cp "build/classes:libs/*" com.woof.agent.VoyagerAgent --steps 120 --bridge http://127.0.0.1:8791
```

Флаги: `--steps N`, `--bridge URL`, `--poll-ms N`, `--quiet`.
Мост по умолчанию слушает `:8791`.

## Контракт моста

`POST /` с JSON-телом, поле `action`:

| action | что делает | ключи |
|---|---|---|
| `snapshot` | состояние мира (игрок, мобы, квесты, инвентарь) | — |
| `step` | выполнить канонический навык по индексу | `idx` |
| `navigate` | идти к цели | `x`, `z` (как принято в клиенте) |
| `raw_move` | элементарное движение/каст | `kind` |
| `respawn` | возродиться | — |
| `explore` | шаг исследования | — |
| `health` | живость моста/вкладки/игры | — |

Ответ всегда JSON: `{"ok": true, ...}` либо `{"ok": false, "error": "..."}`.
**Навык — только из канона** (`core/SkillIndex.java`, 13 навыков + алиасы):
неизвестный навык — исключение, а не молчаливый no-op.

Честный отказ: `CdpBackend` без `--upstream` ещё не портирован целиком — он отвечает
`HTTP 500` и `{"ok":false,"error":"...BRIDGE-PORT..."}`, чтобы никто не принял молчание
за работу. Тест `TestJavaBridge` проверяет именно это.

## Правила, которые нельзя нарушать

1. Не убивать `hermes-agent` / `hermes-gateway` (см. корневой `AGENTS.md`).
2. Не перезагружать игру через CDP.
3. Не трогать исходники игры.
4. Не запускать игру, если пользователь уже в ней.
5. Мост и агент не перезапускать после правок кода — только по явной команде.
