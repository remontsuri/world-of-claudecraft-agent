# world-of-claudecraft-agent

Агент, который сам играет в локальную копию World of Claudecraft, и стенд, на котором
его можно честно проверить. Репозиторий содержит **две линии**, и путать их нельзя.

| Линия | Что | Где | Состояние |
|---|---|---|---|
| **Java-бот** | автономный агент: мост к игре, навыки, квестовые фазы | `woof-agent/` | активная |
| **Коннектом** | схема на 8835 нейронов, обучение читаута, контроли (rewired/ER) | `fly-woc/`, `src/fly_brain/` | на паузе, приёмка объявлена |

## С чего начать

| Кому | Что читать |
|---|---|
| человеку впервые | этот файл → `woof-agent/README.md` → `woof-agent/ARCHITECTURE.md` |
| агенту-исполнителю | `AGENTS.md` → `knowledge/principles.md` → `knowledge/pitfalls.md` → `woof-agent/ROADMAP.md` |
| тому, кто пушит | `GIT-WORKFLOW.md` (правила веток и протокол перед пушем) |
| тому, кто ищет знание | `knowledge/` (индекс — `knowledge/README.md`) |
| тому, что настраивает hermes | `hermes/README.md`, `hermes/TOOLS.md`, `hermes/hooks/` |

## Быстрые команды

```bash
# Java-бот (активная линия) — без игры, всё на фейках
bash woof-agent/tools/build.sh
bash woof-agent/tools/run_tests.sh      # ожидаем: tests passed=3 failed=0
bash woof-agent/tools/run_e2e.sh        # ожидаем: УСПЕХ ... нарушений контракта нет

# Коннектом (пауза)
bash fly-woc/tools/run_checks.sh        # ожидаем: ВСЁ ЗЕЛЁНОЕ
python3 fly-woc/tools/test_device.py    # 25 проверок выбора устройства

# Хуки hermes: проверка, что предохранители работают
bash hermes/hooks/selftest.sh           # ожидаем: ВСЁ ЗЕЛЁНОЕ
```

## Приёмка — это не тесты

Тесты доказывают, что код согласован сам с собой. Проект закрывается живым прогоном:
бот проходит квестовую цепочку в реальной игре, а коннектом сравнивается со своими
перепутанными копиями на тех же сидах. Что считается доказательством, а что —
самообманом: `knowledge/principles.md` и `knowledge/verification.md`.

Пороги метрик объявляются **до** замера: M1 `lvl ≥ 2`, M2 `kills ≥ 10`, M3 `quests ≥ 5`,
M4 `travel ≥ 2.0`. После замера они не двигаются.

## Границы, которые нельзя двигать

* Исходники игры мы не правим; браузер через CDP не перезагружаем; игру не запускаем,
  если пользователь уже в ней.
* Процессы `hermes-agent` и `hermes-gateway` не трогаем никогда.
* Молчаливых фолбэков нет: недоступное устройство, чужая таблица квестов, неизвестный
  навык, неготовая часть моста — это ошибка с текстом.
* `git push --force` запрещён. Рабочая ветка — `backup`; `master` не трогаем.
