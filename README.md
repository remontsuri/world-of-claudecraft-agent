# world-of-claudecraft-agent

Автономный агент, который сам играет в локальную копию World of Claudecraft: мост к игре,
канон навыков, квестовые фазы — и стенд, на котором его можно честно проверить
(фейковые мост и CDP, контрактные тесты, сквозной e2e).

Активная линия одна — **Java-бот** в `woof-agent/`. Вторая линия (коннектом мухи)
**архивирована 2026-09-18** целиком, без удалений: `archive/fly-line/`
(что там, в каком состоянии и как восстановить — `archive/fly-line/README.md`).

## Быстрые команды

Всё без игры и без браузера — на фейках (`tools/fake_bridge.cjs`, `tools/fake_cdp.cjs`).

```bash
bash woof-agent/tools/build.sh        # ожидаем: build ok -> ... (28 files)
bash woof-agent/tools/run_tests.sh    # ожидаем: tests passed=3 failed=0
bash woof-agent/tools/run_e2e.sh      # ожидаем: УСПЕХ ... нарушений контракта нет
bash hermes/hooks/selftest.sh         # ожидаем: хуки: passed=17 failed=0 → ВСЁ ЗЕЛЁНОЕ
```

Эталон последнего e2e (2026-09-17): `steps=120 kills=3 deaths=0 quests_done=1
first_turn_in_step=8`. Сравнение идёт с этими числами, а не с воспоминаниями.

Зависимости: JDK 11, Node 20.x, 6 jar-ов в `woof-agent/libs/` (лежат в репозитории,
`bash woof-agent/tools/fetch_libs.sh` при необходимости). Maven и Gradle не нужны.
Подробно: `woof-agent/DEPENDENCIES.md`.

## Приёмка — это не тесты

Тесты доказывают, что код согласован сам с собой. Проект закрывается живым прогоном:
бот проходит квестовую цепочку в реальной игре и это видно в `[Agent] SUMMARY`.
Что считается доказательством, а что — самообманом: `knowledge/principles.md`
и `knowledge/verification.md`.

Пороги объявляются **до** замера и после него не двигаются. Текущие:
J7 — полный порт `CdpBackend` (e2e идёт без `--upstream`), J8 — живой прогон
`quests_done ≥ 1`, J9 — цепочка `q_spiders` целиком, J10 — агент переживает падение моста.

## Границы, которые нельзя двигать

* Исходники игры мы не правим; браузер через CDP не перезагружаем; игру не запускаем,
  если пользователь уже в ней.
* Процессы `hermes-agent` и `hermes-gateway` не трогаем никогда.
* Молчаливых фолбэков нет: неготовая часть моста, неизвестный навык, чужой процесс на
  порту теста — это ошибка с текстом, а не «сработало как-то».
* `git push --force` запрещён. Рабочая ветка — `backup`; `master` не трогаем.
* `archive/` — не мусорная корзина: оттуда не удаляем и не правим задним числом.

## Архив

`archive/fly-line/` — линия коннектома мухи (схема на 8835 нейронов, PPO-читаут, контроли
`rewired`/`er`). Перенесена `git mv` (180 файлов), поэтому всё восстанавливается одной
командой и остаётся в истории. Итоги линии, включая отрицательные (M3 = 0 квестов во всех
85 эпизодах, `travel_norm` признана непригодной метрикой), — в `archive/fly-line/README.md`.

Тяжёлые данные архива (3 копии коннектома + канон + чек-инты, ~108 МБ) **сняты с
отслеживания**: код, документы и доказательства (`benchmark_*.json`, таблицы квестов,
`train_log_*.json`) в git остались. Отслеживаемое дерево: 117 МБ → 11 МБ.
Возврат файла — `git checkout 40f3ba6 -- <путь>`; контроли регенерируются из канона за 18 с.

`recover.py` и `dataset_collector.py` в корне — инструменты моста (`:8791`), к мухе не
относятся; `tools/push_backup.sh` — общий push-хелпер с проверкой fast-forward.

## Лицензии и заимствования

* У самого репозитория файла лицензии нет — это отдельное решение владельца, а не
  следствие невнимательности; до его появления внешний код сюда не переносим.
* Код сторонних проектов берём только с лицензией (MIT / Apache-2.0 / GPL-совместимо) и с
  указанием источника. Репозитории **без лицензии** — источник идей, а не кода.
* Данные MaleCNS (Janelia FlyEM и соавторы) в архиве — **CC BY 4.0**: атрибуция обязательна
  в производных артефактах, фигурах и отчётах. Хеши исходных файлов — в
  `archive/fly-line/fly-woc/data/manifest.json`.

## Ветки
